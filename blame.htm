Git Blame

git blame is a Git command that annotates each line in a file with:

  • The last commit that modified the line
  • The author of the commit
  • The timestamp of the change
  • The line number and code content

How to Use

git blame filename

Press Enter to scroll through the file.

Press q to quit.

Options

View a specific range of lines:

git blame -L 2,5 filename

Show the author’s email:

git blame -e filename

View commits since a specific time:

git blame --since=3.months filename

Ignore whitespace changes:

git blame -w filename

Using GitHub

GitHub also provides a Blame button on file pages. Clicking it shows the same information as git blame. You can click line numbers to view commit history.
